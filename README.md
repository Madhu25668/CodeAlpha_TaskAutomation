# CodeAlpha_TaskAutomation
A beginner-friendly Python automation project that moves JPG/JPEG files from one folder to another using the os and shutil modules.
# 📂 Task Automation with Python Scripts

## 📌 Project Overview

This project is developed as part of the CodeAlpha Python Programming Internship.

The script automatically moves all JPG/JPEG image files from a source folder to a destination folder. It demonstrates Python file handling, folder management, exception handling, and automation using built-in modules.

---

## ✨ Features

- Move JPG/JPEG files automatically
- User-friendly console interface
- Validates folder paths
- Displays moved file names
- Shows total files moved
- Handles common errors gracefully
- Beginner-friendly code with comments

---

## 🛠 Technologies Used

- Python 3
- os module
- shutil module

